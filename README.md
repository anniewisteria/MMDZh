【简介】
纯运行时汉化插件，启动 MMD 后在内存中翻译界面，
不修改 MMD、MME、模型或工程文件的任何一个字节。
卸载插件后一切恢复原样。

【安装】
1. 确认 MMD 目录下已有 MMDPlugin.dll（没有的我release版本包里放了，作者老师允许二配）；
2. 把本压缩包里的 Plugin 文件夹整个复制到
   MikuMikuDanceE_v932x64 文件夹内，与现有 Plugin 文件夹合并；
3. 最终路径应为：
   ...\MikuMikuDanceE_v932x64\Plugin\MMDZh\MMDZh.dll
   安装好后MikuMikuDance.exe本体边上应有MMDPlugin.dll、d3d9.dll、d3dx9_43.dll，以及Plugin和Data文件夹。
5. 启动 MMD，菜单栏出现「中文汉化」即安装成功。

（如果你用的mmd是那种mme的dll跟mmd在一起的把你mmd包里的MMEffect.dll,d3d9.dll，MMHack.dll都删掉，我的plugin文件夹里已经放好了mme，把我配布插件包plugin文件夹外的d3d9.dll,d3dx9_43.dll，MMDPlugin.dll放到你mmd.exe边上就好）


【卸载】
把MMDZh从plugin文件夹拿出来即可，无残留。

【功能】
· 菜单栏全量汉化（含 MMEffect 特效菜单）
· 按钮 / 面板 / 对话框汉化
· GDI 自绘文字汉化（含竖排折叠标签）
· MME 特效配置窗口与报错框汉化
· 骨骼名、表情名等用户数据保持原文，不强行翻译


【与其他插件共存】
已做窗口隔离，可与 MMPlus、MMAccel、MME 等同装；
仅处理 MMD 自身窗口，不碰其他插件创建的界面。
若个别插件窗口出现异常，可临时移除本插件验证。
